# LĐN4 Đề 5 – Quizizz Frontend

Mở `index.html` trực tiếp bằng trình duyệt.

## Nội dung
- 85 câu: 28 文字・語彙 + 17 文法 + 12 読解 + 28 聴解.
- Có lọc theo từng phần.
- Có chấm điểm và xem lại đáp án.
- Câu đọc hiểu hiển thị toàn bộ đoạn văn liên quan.
- Dấu gạch chân trong phần chữ dùng `<u>` để giữ đúng kiểu nhấn mạnh.
- Phần 聴解 chỉ làm lựa chọn đáp án. Các câu cần hình trong đề dùng placeholder `DEV: thêm ảnh/audio`.

## Cấu trúc
- `index.html`
- `style.css`
- `app.js`
- `README.md`
